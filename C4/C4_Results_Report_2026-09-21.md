# C4 探索性实验结果汇报

2026 年 9 月 21 日｜组内讨论稿｜依据 C4 integrated protocol v3

## 1. 本轮回答了什么

**本轮已完成最新版 C4 的 Stage 0、Stage 1 meeting pilot，以及 Stage 2 的两个预定更新分叉。结果显示：代理优化与真实标签评估经常不一致；两个预定长时域终点均出现固定参考集 CE 上的反馈额外伤害，但尚未得到持续自退化、稳定性边界或相变证据。**

最值得跟进的是 block 5 后的候选更新：它使固定参考集 Q 的 CE 立即下降 0.04593；继续 1,410 步后，接受它的闭环路径反而比拒绝路径高 0.26629。改用拒绝路径生成的外部监督回放时，接受仍优于拒绝，CE 低 0.05069。不过，效应在中途多次变号，这个终点结果不能代表全程恶化。

| C4 阶段 | 最新计划要求 | 本轮实际状态 |
|---|---|---|
| Stage 0 | 算法、数据隔离、日志、恢复、吞吐核验 | 已完成；12 项软件检查通过，真实数据预检通过 |
| Stage 1 | 两个反馈端点、1 个种子、2 个完整循环 | 已完成；两组各 30 blocks、2,820 次更新 |
| Stage 2 | 预定节点的接受/拒绝及闭环/回放比较 | 已完成；block 5/15 两节点，H=20/94/1410 |
| Stage 3 | 独立扰动、有限响应、闭合性与 Jacobian 验证 | 未执行；现有曲线不代替该阶段 |
| Stage 4 | 冻结分析、新种子、未使用的确认集 | 未执行；确认集保持未查看 |

**实验类型为 C4-natural / Type B。** 系统是 student → EMA teacher → 伪标签与置信度筛选 → 下一轮 student。原始图像序列来自外部，内生的是监督信号及选择掩码。自然学习器没有基于标签的接受门槛；“执行了一次更新”不等于“evaluator 判定它有效”。本实验也没有 mixture-to-single-heir 压缩步骤，继承损失和 Bayesian hypercompression 不适用。

### 实际冻结设置

- CIFAR-100-C，severity 5，固定顺序的全部 15 种 corruption，循环两次；seed=101。
- 源模型 Hendrycks2020AugMix_ResNeXt，6,900,132 个参数。训练全部 student 参数，冻结 BN running statistics；无随机源权重恢复，非完整 CoTTA。
- 反馈向量 γ=(λ,β)：只运行 (0,0.001) 与 (1,0.001)。代码中的标量 `gamma` 对应 λ。λ=0 使用固定源监督，仍继续训练；λ=1 使用演化 EMA teacher。
- SGD：学习率 0.001、momentum 0.9、weight decay 0；batch size 64，置信度阈值 0.9，每个非空 batch 更新一次。
- 原始图像 ID 分层隔离：训练 6,000、保留 gate 1,000、探索 audit 1,500、确认 audit 1,500。标签不参与自然适应或接受决策。
- Q：从探索 audit 中每类取最小 ID，100 张基础图像 × 15 种 corruption，共 1,500 个固定图像-corruption 对。它是探索面板，不是独立确认测试。

## 2. Stage 0 与 C4-1：实现核验和局部评价偏差

两组均完成所有 2,820 次计划更新，无空选择 batch。源模型 clean sanity check 使用训练池内 1,000 个 ID，错误率 20.8%、CE 0.78928；它只检查加载路径，不是新的 benchmark 结果。

真实数据运行前修复了 uint8 标签索引错误；分叉实现前修复了 optimizer momentum 状态共享问题。受影响的预检尝试独立保留，正式结果由修复后的实现产生。数据文件、完整状态恢复、固定目标下代理损失重算、原始记录及 replay 一致性检查均通过。

### 局部问题：代理损失下降，是否意味着本次模型变好？

代理变化使用完全相同的图像、强增广、伪标签、mask 和归一化，且在 EMA 更新前计算。带标签的局部 probe 在每个 block 首尾各测一次，每次使用固定的 128 个探索 audit ID；每组共 60 个 probe。符号阈值为 10⁻⁶。

| 测量 | λ=0 | λ=1 |
|---|---:|---:|
| 全部更新中代理 CE 下降 | 2,815 / 2,820 | 2,817 / 2,820 |
| 全部更新中代理 CE 上升 | 5 / 2,820 | 3 / 2,820 |
| probe：代理下降、局部 audit CE 下降 | 38 / 60 | 43 / 60 |
| probe：代理下降、局部 audit CE 上升 | 22 / 60 | 17 / 60 |
| probe：代理上升、局部下降 / 局部上升 | 0 / 0 | 0 / 0 |
| probe：近零 / 空 mask | 0 / 0 | 0 / 0 |

**观察：** 在预定 probe 中，36.7%（λ=0）和 28.3%（λ=1）的更新出现“优化目标变好、局部带标签 CE 变差”。这支持有限样本上的 evaluation–performance gap。它不意味着这些比例适用于所有更新，也不证明任何一次更新具有总体分布上的有效性保证。两个 λ 下均有这一现象，不能仅凭此把它归因于内生反馈。

## 3. Stage 1 / C4-2b：固定参考分布上的表现

下表均在相同 Q 上评估。CE 是计划中主要的机制/有效性读数；分类错误率是 benchmark 表现指标。两者都必须报告。冻结 source 的 CE=2.45255、错误率=45.47%，在各时点不变。

| 时点 / 对象 | λ=0 CE | λ=0 错误率 | λ=1 CE | λ=1 错误率 |
|---|---:|---:|---:|---:|
| 初始 student / teacher | 2.45255 | 45.47% | 2.45255 | 45.47% |
| 第 1 循环末 student | 2.58033 | 55.07% | 2.83018 | 55.53% |
| 第 2 循环末 student | 2.43198 | 49.93% | 2.89772 | 52.93% |
| 第 1 循环末 teacher | 1.77089 | 41.73% | 1.90086 | 43.67% |
| 第 2 循环末 teacher | 1.91454 | 42.80% | 2.31199 | 46.60% |

**Student 观察：** λ=1 的末端 CE 劣于 source，且第 2 循环末比第 1 循环末更高；但错误率在两个循环末之间下降。λ=0 的 CE 从第 1 循环末恢复，到最后略低于 source，而错误率仍高于 source。完整曲线有明显波动与恢复，不能概括为持续恶化。

**Teacher 观察：** EMA teacher 的 CE 在两个 λ 的两个循环末均低于对应 student。λ=1 teacher 的 CE 从 1.90086 上升到 2.31199，但仍低于 source CE；它的错误率最终升至 46.60%。因此，结论依赖被评估对象与损失指标，不能把 student 结果直接称为“整个系统都退化”。Teacher–student 差距也不是本实验中的继承损失。

![C4-2b：相同固定参考面板上的 student、teacher 与 source。图中的 gamma0/1 对应 λ=0/1，β 固定。](C4-2b_fixed_reference.png)

**解释边界：** Q 固定，避免了“后一个 domain 更难”带来的直接混淆；但 Q 只含 100 个基础图像的重复 corruption 版本。当前没有跨种子置信区间，不能把 1,500 对当作 1,500 个独立研究重复。

## 7. Stage 2 / C4-5：怎样识别反馈的额外作用

在第一循环的 block 5 和 block 15 后，使用下一域的第一个非空更新作为候选。两个节点在查看其后果前指定，无论局部符号如何都运行并报告。接受与拒绝保存完整 student、teacher、optimizer 状态，从相同后续图像与增广序列继续。

先从拒绝状态生成闭环参考 tape，保存未来每个 batch 的目标概率、伪标签、confidence mask 和输入键。接受/回放路径使用这份外部 tape，自己的 teacher 不再决定训练目标或 mask。**回放仍继续训练；它切断的是 student 对未来监督的影响，不是冻结模型，也不是仅冻结本已外生的图像流。**

记 L 为固定 Q 上的 student CE，定义：

- A_cl(h) = L_accept,closed(h) − L_reject,closed(h)：闭环下接受更新的后代效应。
- A_ol(h) = L_accept,replay(h) − L_reject,replay(h)：共同外部监督下的后代效应。
- I(h) = A_cl(h) − A_ol(h)：指定回放干预下，反馈使接受效应额外改变多少。正值表示更不利。

拒绝/回放与拒绝/闭环在前 20 步显式验证一致，随后用确定性递推的等价关系复用拒绝路径。三个完整分支实际运行；没有把第四条长路径描述为另一次独立实测。

| 父节点 | 后续步数 h | A_cl | A_ol | I |
|---|---:|---:|---:|---:|
| block 5 | 0（立即） | −0.045932 | −0.045932 | 0 |
| block 5 | 20 | +0.005858 | +0.005858 | 0 |
| block 5 | 94 | −0.119639 | −0.116541 | −0.003098 |
| block 5 | 1,410 | +0.266292 | −0.050690 | +0.316982 |
| block 15 | 0（立即） | +0.046558 | +0.046558 | 0 |
| block 15 | 20 | +0.036279 | +0.036013 | +0.000266 |
| block 15 | 94 | +0.138922 | +0.443354 | −0.304432 |
| block 15 | 1,410 | +0.069601 | −0.052072 | +0.121673 |

表内数值统一取 Sapelo 输出。H20/H94/H1410 是相同路径的不同长度，不是独立重复。4090 与 L40S 的 H94 contrasts 最大差异不超过 4.77×10⁻⁷，支持迁移后的数值复现，不增加统计样本量。

**Block 5 的短期反转不能归因于反馈：** h=5/20 时，闭环和回放的接受效应相同。到 h=94，该更新再次有益。只有在指定长终点，才出现“即时有益、闭环后代有害、回放后代仍有益”的联合结果。

## 8. C4-5：完整曲线和结果边界

![预定 block 5 分叉：左为固定 Q 的绝对 CE，右为接受效应和反馈交互。](C4-5_after5_H1410.png)

![预定 block 15 分叉：全部 audit 时点均保留，反馈交互多次变号。](C4-5_after15_H1410.png)

**两个预定 H1410 终点的 I 均为正，但完整轨迹不是持续有害。** H94 两个 I 均为负；完整曲线上还有多次正负切换。这里得到的是特定父节点、监督干预和时域下的反馈额外伤害，不是单调误差放大定律。

预算 H1410 等于 15 域 × 94 batches。候选消耗下一域的第一个 batch，所以原始域循环边界落在 h=1409；该边界两节点的 I 也为正，分别 +0.237884、+0.211858，但仍不能消除中间的符号反转。报告保留两个时点，避免混淆“循环长度预算”和“原始循环结束位置”。

长分叉中，接受闭环相对拒绝 tape 改变了 9,252 / 6,892 个伪标签事件和 4,111 / 3,683 个 mask 事件（block 5 / 15）。这些是重复样本呈现的计数。因为干预同时固定目标和 mask，目前无法判断哪条渠道承担了多少效应。

## 9. 绝对退化、相对伤害与下一步决策

### 绝对表现并未统一变差

| 父节点 / 路径 | 初始 CE | H1410 CE | 初始错误率 | H1410 错误率 |
|---|---:|---:|---:|---:|
| 5 / 拒绝闭环 | 2.99013 | 2.78637 | 65.73% | 55.27% |
| 5 / 接受闭环 | 2.94420 | 3.05266 | 64.67% | 56.73% |
| 5 / 接受回放 | 2.94420 | 2.73568 | 64.67% | 51.33% |
| 15 / 拒绝闭环 | 2.83018 | 2.76474 | 55.53% | 50.47% |
| 15 / 接受闭环 | 2.87674 | 2.83434 | 56.40% | 52.13% |
| 15 / 接受回放 | 2.87674 | 2.71267 | 56.40% | 53.07% |

所有路径的分类错误率相对各自起点都改善了；block 15 的接受闭环错误率还低于接受回放，尽管 CE 更高。**“接受后比拒绝差”“反馈比指定回放更有害”“绝对风险不断升高”是三个不同结论。本轮仅在部分预定比较上支持前两个。**

### 按最新版 C4 可以写到哪一步

| 目标 | 当前证据判断 |
|---|---|
| 代理评价与局部带标签表现不一致 | 已观察到；限于预定的有限样本 probe |
| 即时有益更新在指定未来时域产生更差后代 | block 5 的固定 Q-CE 已观察到 |
| 内生监督相对指定回放额外加重后果 | 两个 H1410 终点已观察到；中途方向不固定 |
| 持续 recursive deterioration | 尚未建立；同域返回整体改善，轨迹反复恢复 |
| 四维诊断状态是闭合的动态系统 | 尚未检验；仅保存了所需诊断读数 |
| Jacobian / 谱半径 / 相变边界 | 未估计、未验证；C4-6、C4-7 尚无结果 |
| Bayesian hypercompression / 有损继承机制 | 本实验不适用 |
| 可推广的 RSI 结论或 benchmark 优势 | 尚不支持；单种子、单数据集、简化 CTTA |

**建议的下一项实验：先做冻结设置的跨种子复现。** 保留同样的两个父节点、λ/β、H94/H1410 和两项损失指标；事先规定同时报告终点效应与全程 audit 轨迹，避免再从曲线挑窗口。先在探索 audit 上复现现象；若进入计划的 Stage 4，再冻结主比较、实际有意义的效应阈值和分析方案，使用新种子 303/404/505/606/707 及 untouched confirmation audit。不能用当前数据代填尚未确定的成功标准。

若长终点效应能复现，再分别固定伪标签或 mask，区分渠道。Stage 3 按 v3 需要独立 student/teacher 扰动、尺度检查、rank/conditioning、momentum 闭合性反例及 holdout 预测；它不是从现有两条轨迹直接拟合一个 VAR 就能完成的。若复现不稳，应保留负面结果并停止升级“持续退化”的 claim。

### 组会可用结论

在这个自然 CTTA 学习器中，伪标签训练目标的下降不能保证局部标签风险改善。预定分叉进一步给出了一个即时改善、但在指定长时域产生更差闭环后代的实例；共同监督回放表明，这个后代效应与内生监督渠道有关。不过，效应符号随时域变化、CE 与错误率不完全一致，同域返回整体改善。当前最合理的推进方向是复现并界定这一有限时域现象，而不是宣布已发现持续自退化或相变。
